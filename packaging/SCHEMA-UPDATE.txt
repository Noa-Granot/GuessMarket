Schema update - the three typos were fixed
==========================================

The course published a corrected schema and corrected sample files. Three
element and attribute names changed:

    comision            ->  commission
    GM-mareket-maker    ->  GM-market-maker
    inital              ->  initial

Everything else in the schema is identical.

WHAT CHANGED IN THE PROJECT
    generated\Comision.java        renamed to  Commission.java
    generated\GMMareketMaker.java  renamed to  GMMarketMaker.java
    generated\GMOrderBook.java     getInital() renamed to getInitial()
    generated\GMEvent.java         getComision() renamed to getCommission()
    generated\GMUser.java          getGMMareketMaker() renamed to getGMMarketMaker()
    XmlLoader.java                 updated to match
    schema\GM-EX2-Schema.xsd       replaced with the corrected one
    samples\*.xml                  replaced with the corrected ones
    the "Comision" filter label and column header now read "Commission"

AFTER EXTRACTING
    Delete these two files if they are still in the project, because the
    extract adds the new names but cannot remove the old ones:

        engine\src\guessmarket\engine\xml\generated\Comision.java
        engine\src\guessmarket\engine\xml\generated\GMMareketMaker.java

    Then Build -> Rebuild Project.

    A quick way to be sure nothing is left: Ctrl+Shift+F and search for
        comision
        mareket
        inital
    All three should find nothing.

The old sample files will no longer load, which is correct: they use the
old spellings and the schema no longer allows them.
