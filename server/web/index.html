Guess Market server

The server is running. The JavaFX clients talk to the addresses below; this page only confirms the war deployed.

Who you are

  • POST /login?username=NAME registers a name and starts a session
  • GET /whoami the name this session is logged in as
  • GET /logout ends the session; the user stays in the market

Reading the market

  • GET /events every event
  • GET /event?id=1 one event in full: books, trades, holdings, prices
  • GET /users everyone: name, balance, whether they are a market maker
  • GET /user-state your own account in full
  • GET /quote?id=1&option=0&quantity=100 what a purchase would cost

Changing the market

  • POST /upload multipart, one part named file
  • POST /funds?amount=1000 adds money to your own account
  • POST /open?id=1 opens your event for trading
  • POST /buy?id=1&option=0&quantity=100 buys shares of an LMSR event
  • POST /order?id=2&option=0&side=Buy&quantity=50&price=0.4 submits an order
  • POST /close?id=1&option=0 closes your event on the winning option

Polling

Every answer carries the market version in the X-Market-Version header. A client that sends it back as &since=N gets 204 No Content while that is still the current version, so a poll every second costs almost nothing until something actually changes.
